APB Interface SPI Master IP Core RTL Design

Overview

This project focuses on the RTL design and verification of an APB Interface SPI Master IP Core using Verilog HDL.

The design integrates an APB interface for register access with an SPI master controller for serial communication.

Project Structure

* rtl/ — Verilog RTL design modules.
* tb/ — Simulation testbenches.
* docs/architecture/ — Architecture diagrams.
* docs/waveforms/ — Simulation waveform screenshots.
* docs/lint/ — Lint documentation and approved reports.
* docs/synthesis/ — Synthesis documentation and approved reports.
* scripts/ — Simulation and tool scripts.
* results/ — Selected project results.
